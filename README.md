# RibbonKit

Reusable SwiftUI views for a sliding ribbon selector and a reference navigator.

- `SliderScreen` — two linked ribbons for selecting a value. Spec: `style/View_SlidingRibbon.md` in richrwells/knowledge.
- `ReferenceNavigatorView` — list ribbon with a content column. Spec: `style/View_Ref-Nav.md` in richrwells/knowledge.
- `RibbonShell` — shared three-band layout.

Add this package to an app and `import RibbonKit`. Do not copy the sources.
